# Custom UDF plugins
### Develop a plugin
Use `aios/plugins/havenask_plugins/udf_plugins` as the reference when developing a UDF plugin.

### Use a plugin
After you register the plugin in `aios/plugins/havenask_plugins/udf_plugins/HavenaskUdfFactory.cpp`, rebuild the image to use the plugin.
