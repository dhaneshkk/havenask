# havenask-1.0.0
## Overview
* Open-sourced more component code, such as swift and suez.
* Expanded distributed capabilities: online and offline tasks are managed by suez admin and bs admin, and operations are managed by hape.
* Added direct-write tables.
* Added the catalog feature.
