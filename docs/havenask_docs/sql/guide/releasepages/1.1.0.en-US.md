# havenask-1.1.0
## Overview
* Changing the schema of a full table now triggers a full build, and the new full index is switched in automatically.
* Added updating of the load strategy.
* Added updating of binaries, startup parameters and similar settings.
* Added spatial indexes and date indexes.
* Added BM25.
* QRS and searcher can now be placed on the same machine.
