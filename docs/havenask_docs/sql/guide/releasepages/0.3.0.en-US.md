# havenask-0.3.0
## Overview
* Added distributed deployment of Havenask. For details, see [Introduction to hape](../../petool/intro.md).
* Added real-time data updates.
    * [Real-time write example](https://github.com/alibaba/havenask/wiki/%E5%AE%9E%E6%97%B6%E5%8A%9F%E8%83%BD%E4%BD%BF%E7%94%A8%E6%96%87%E6%A1%A3) (in Chinese)
    * [Real-time writes with hape](../../petool/scene.md)
* Added [examples and documentation](https://github.com/alibaba/havenask/tree/v0.3.0/aios/plugin_platform) for function plugins, summary plugins, bs processor plugins and bs reader plugins.
