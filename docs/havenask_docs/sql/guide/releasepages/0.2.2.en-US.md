# havenask-0.2.2
## Overview
1. Added vector retrieval. For details, see [Vector indexes](../../indexes/vector.md).
2. Integrated the widely used open-source jieba analyzer to improve havenask's tokenization. For details, see [jieba analyzer](https://github.com/alibaba/havenask/wiki/Jieba%E5%88%86%E6%9E%90%E5%99%A8) (in Chinese).
